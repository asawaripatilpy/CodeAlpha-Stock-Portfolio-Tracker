# 📈 Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker that calculates total investment value using manually defined stock prices.

This project allows users to add multiple stocks, enter quantities, calculate investment values, view portfolio distribution, and save the portfolio as TXT or CSV files.


## 🎯 Project Objective

The goal of this project is to build a beginner-friendly stock portfolio tracker using Python fundamentals such as dictionaries, lists, functions, loops, conditional statements, arithmetic operations, exception handling, and file handling.

> Note: Stock prices are manually defined for educational purposes and are not live market prices.

## ✨ Features

- 📋 Display predefined stock prices
- ➕ Add multiple stocks to the portfolio
- 🔢 Enter quantity of shares
- 💰 Calculate individual investment value
- 📊 Calculate total investment value
- 📈 Display portfolio share percentage
- ⚠️ Validate stock symbols
- 🛡️ Handle invalid quantities
- 📄 Save portfolio as TXT
- 📊 Save portfolio as CSV
- 🖥️ Clean and interactive terminal interface
